`git log` is a command you can put in the terminal. It shows all commits and its metadata as well as merge requests

### Anatomy of a Commit
Includes 
+ Commit hash
	+ Unique and long
	+ Can refer to it with first 4-5 characters
+ What branches point there
+ Author
+ Date
+ Commit Message
###### Commit message conventions
+ Short and concise that roughly described what happened (10ish words)
+ DO NOT make long messages
+ These are public, so other people can see them
+ Make them different between commits so you can distinguished what happened
	+ Don't have the same message (e.g. "fixed bug")


`HEAD` is the "bookmark name" that tells you were you currently are in the tree


A statement is one instruction
```
let x = 5;
```

Each statement is separated with a `;`

You can have multiple statements on one line
```
let x = 5; 6 + 10; console.log("Hello World");
```

- Whitespace is ignored, so statements can span multiple lines
- Hyphens are not allowed as they are reserved for subtractions
- Single line comments use `//`
- Multi-line comments use `/*` to start and `*/` to end

# HTTPS Cloning 
- To clone a repository use the following command

$$\text{git clone \{some repository link\}}$$

- Tracked vs Untracked 
$$\text{git status}$$
- To stage/track and or prepare for a commit we do the following
$$\text{git add .}$$
- To commit 
$$\text{git commit -m "(some message)"}$$
- Push changes
$$\text{git push}$$

- To pull from our given repositories

$$\text{git pull}$$

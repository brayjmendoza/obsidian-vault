In C, a `struct` is used to aggregate multiple data members together into a single thing
+ No private data
+ No member functions
+ External code operates on the data in a `struct`

Structs can do anything classes can do, but some key differences are
+ Data members are public by default
	+ In a `class`, they are private by default
+ The `class` and `struct` keywords are not interchangeable

+ Instances of `class`es take care of themselves (it's self-contained)
+ Data bound in a `struct` is "just the data" and nothing else

**Lexical analysis** is splitting a program's text into **tokens**, its smallest meaningful pieces, as the first step of parsing.

A **token** is an atomic piece of syntax: a reserved word (e.g., `for` or `return`), an identifier (e.g., `count`), a literal value (e.g., `0` or `"Hello"`), an operator (e.g., `<` or `++`), or punctuation (e.g., `{` or `;`). To **tokenize** or **lex** is to turn concrete syntax into a list of tokens, and a **tokenizer** or **lexer** is code that does it. Whitespace usually separates tokens but isn't one, so the lexer drops it.

Tokenizing is an intermediate step: the parser then works on tokens instead of characters, so it can ask "is the next thing a number?" rather than reading digits one at a time (see [[Parsing]]). A tokenizer is written in two steps:

1. **A data type for tokens,** with a constructor for each kind (see [[Algebraic Data Type]]). A token that carries a value, like a number, gets a field for it.
2. **A function from a string to a list of tokens,** which looks at the first character, emits a token, and recurs on the rest. Characters that can't start any token are an error.

More generally, lexers are usually defined by regular expressions, one per kind of token, and generated by tools (e.g., lex and flex). The usual rule when several tokens could match is **longest match**: `count` is one identifier, not five one-letter ones.

# Example

The smallest pieces of a line of C:

| Text | Token kind |
|---|---|
| `int` | Reserved word (a type) |
| `count` | Identifier |
| `=` | Operator |
| `0` | Literal number |
| `;` | Punctuation |
| `"Hello, World!"` | Literal string |

A tokenizer for Arith:

```haskell
data Token
  = CrossToken | DashToken | StarToken | SlashToken
  | LParenToken | RParenToken
  | NumberToken Double
  deriving (Eq, Show)

tokenize :: String -> [Token]
tokenize [] = []
tokenize ('+' : rest) = CrossToken : tokenize rest
tokenize ('-' : rest) = DashToken : tokenize rest
tokenize ('*' : rest) = StarToken : tokenize rest
tokenize ('/' : rest) = SlashToken : tokenize rest
tokenize ('(' : rest) = LParenToken : tokenize rest
tokenize (')' : rest) = RParenToken : tokenize rest
tokenize s@(c : rest)
  | isSpace c = tokenize rest                         -- skip whitespace
  | isDigit c = let (num, s') = span isDigit s        -- the longest run of digits
                in NumberToken (read num) : tokenize s'
  | otherwise = error ("Invalid character: " ++ show c)

tokenize "12 + (3*4)"
-- [NumberToken 12.0, CrossToken, LParenToken, NumberToken 3.0, StarToken, NumberToken 4.0, RParenToken]
```

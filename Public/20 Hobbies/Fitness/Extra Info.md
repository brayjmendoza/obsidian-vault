deload every 4th week
## De-Loading
- Calisthenics
    - Do half of the sets listed (i.e. reduce volume by 50%)
    - Keep warm-ups and mobility finishers unchanged
    - No progression or hard skill attempts
- Running
    - Normal run: keep as is or reduce mileage slightly (10-15%)
    - Do an easy run instead of a tempo run
    - Cut long run length by 30-40%, keep same pace
- Do the de-load week early if you notice 2 of the following
    - Worse performance
    - Lingering joint aches
    - Tanking sleep/motivation

## Recovery & Auto-Regulation
- Try to evenly distribute fatigue
    - If yesterday was HARD run → do light calisthenics or upper-focused
    - If yesterday was HARD calisthenics → do easy run
    - If both were moderate → either order is fine
    - Don’t go hard on leg calisthenics after a hard run the day before
    - If Friday explosive legs is too much, do more mobility/core, just be sure Friday is light legs
- Autoregulation rule: If fatigue is high on a given day
    - Reduce volume (not intensity first)
    - Keep movement quality high
    - Avoid failure sets
    - Listen to your body!

## Extra Calisthenic Information
- Progression Rules
    - Strength Benchmarks
        - Hit top end of rep range for all sets
        - Maintain form (no momentum cheating)
        - No joint pain
    - Control Benchmarks
        - 2-3 second controlled eccentric (i.e. lowering)
        - Full range of motion
        - Stable breathing
    - Consistency Benchmark
        - Same performance 2 sessions in a row
- Note on isometric holds
    - How long should I do a hold for in my sets?
        - Hold as close to benchmark/target time with good form as possible
        - The moment form breaks, stop the set
        - Move to next exercise in the progression once you can hit the target time, with good form, for all working sets
- Note on Wednesday Nordic curls
    - Soreness typically peaks 24-48 hours after doing these
    - Downgrade Thursday tempo run into a normal or easy run if too sore
